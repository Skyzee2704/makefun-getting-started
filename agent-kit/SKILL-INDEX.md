## How the router picks

Bounty detection runs first. A bounty task never goes through the general orchestrator — it goes `bb-methodology` → `bug-bounty-null200ok` → `evm-audit-skills` → `claude-cyber-security-skills` → `bugbountyrules`, in their newest merged versions. Everything else routes by domain: game-3d, assets, Roblox, orchestration. If a skill is missing for a job, the router says so instead of guessing — a missing skill is a fact, not a reason to improvise one.
